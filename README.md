# Medical_IoT_system
For some IoT systems that require high data confidentiality, the encryption at the data 
link layer may not necessarily meet the user's requirements for confidentiality. In this case, 
when designing the communication protocol, it is generally assumed that the data link layer 
cannot be fully trusted.
Our project is designed based on this scenario. In this project, we will add a set of 
encryption and decryption algorithms on top of the data link layer (wifi communication) to 
achieve higher confidentiality. On this basis, we will implement highly confidential data or 
command transmission between the ESP32 development board and one or more laptops.
